# ApaKabaR — Pedoman tampilan: persis WhatsApp

Tujuan: pelayan yang sudah biasa memakai WhatsApp tidak perlu belajar lagi. Bila ragu, **ikuti WhatsApp**.

## Struktur layar
- Tab bawah (Android: atas): **Chat**, **Pembaruan** (kanal pengumuman), **Komunitas/Grup**, **Panggilan** disembunyikan di v1.
- Daftar chat: avatar bulat, nama, cuplikan pesan terakhir, jam, lencana hijau jumlah belum dibaca, sematkan, arsip, bisukan.
- Ruang chat: header (avatar, nama, status "online/terakhir dilihat"), gelembung hijau (keluar) dan putih (masuk), ekor gelembung, pemisah tanggal, kolom ketik dengan tombol kirim bulat hijau.
- Status pesan: jam kecil, satu centang (terkirim), dua centang abu (diterima), dua centang biru (dibaca).
- Aksi: balas (geser), teruskan, salin, hapus untuk saya / untuk semua, bintangi, info pesan, cari di chat.
- Grup: info grup, daftar anggota, admin grup, tautan undangan dimatikan (anggota dikelola admin).
- Pesan sistem berwarna kuning pucat: "Pesan dan panggilan terenkripsi ujung ke ujung...", "Kode keamanan berubah".
- Pengaturan: profil, privasi (terakhir dilihat, tanda dibaca), notifikasi, penyimpanan, bantuan.

## Hal yang sengaja berbeda (aturan keamanan HKBP)
- Pendaftaran hanya untuk nomor terdaftar sebagai pelayan; ada layar "Menunggu persetujuan admin".
- Satu perangkat per akun.
- Notifikasi hanya "Pesan baru".
- Tidak ada media, panggilan, status, atau tautan undangan grup di v1.

## Panduan visual
Warna, ikon, dan jarak mengikuti WhatsApp versi Android terbaru (hijau tema, gelembung, centang). Bahasa antarmuka Indonesia dengan istilah WhatsApp apa adanya ("Chat", "Grup", "Pesan baru").
